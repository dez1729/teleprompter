# Teleprompter

A local teleprompter. Paste a Script, and the Prompter scrolls it at a constant Speed through an adjustable Reading window.

```
pnpm i && pnpm dev
```

Open http://localhost:4748. Vocabulary lives in [GLOSSARY.md](./GLOSSARY.md).

Keys: Space play/pause, Up/Down speed, +/- text size, Home restart, [ ] Reading window height, Left/Right step a line, Shift+Left/Right step a paragraph. Mouse wheel or drag scrubs.
